# 利用标靶扫描锐度计算片夹垫高高度（135调焦卡）

> 适用场景：在使用爱普生平板扫描仪扫描底片时，原装片夹可能高度不满足最佳锐度的焦平面高度，此时可以用本工具找出最佳垫高的高度。
>
> 适用于所有平板扫描仪。

## 推荐操作流程

> 图片下方直接展示；点击蓝色链接可查看原图

1. **准备垫片**：按 [垫片粘贴示意图](垫片粘贴示意图.webp) 粘贴垫片；垫片规格参考 [0.2mm](垫片规格0.2mm.webp) / [0.1mm](垫片规格0.1mm.webp) ，pdd扫一扫可购入。默认 **B组 垫高 4mm**（A组 = 0），也可改用其他高度，告诉 AI 即可。
2. **装载调焦卡**：按 [调焦卡放置示意图](调焦卡放置示意图.webp) 把 135 调焦卡装入片夹；[调焦卡实物图](调焦卡实物图.webp) ，闲鱼扫一扫可购入。
3. **扫描**：按 [epson\_scan操作流程](epson_scan操作流程.webp) 操作得到长条扫描图像。等待时，可以同步安装 tilt-focus-sweep skill，如下 。

   对话输入（安装 skill）：
   ```
   安装 https://github.com/Typhoon-line/film-scan_epson/tree/main/tilt-focus-sweep
   ```
4. **第 1 遍·粗测（第 1 张 TIFF）**：按大跨度装夹（B组 4mm / A组 0），扫描得到第 1 张 TIFF 喂给 AI。得到结果图。

   对话输入（第 1 遍）：
   ```
   B组 垫高 4mm
   D:\垫高计算\V700\img404.tif    ← 替换为你的扫描文件位置
   一测
   ```
5. **第 2 遍装夹**：按红字推荐结果 调整垫片高度——仍是**A组低 B组高**（跨度 1mm）。
6. **第 2 遍·精测（第 2 张 TIFF）**：再次扫描得到第 2 张 TIFF 喂给 AI。结果图会给出最终推荐结果。

   对话输入（第 2 遍）：
   ```
   D:\垫高计算\V700\img405.tif    ← 替换为你的扫描文件位置
   二测
   ```
7. **最终垫高**：4 个支脚统一垫到推荐结果高度，即可提升扫描精度。

> **整个测试只需提交 2 张扫描 TIFF**：第 1 张 = 粗测（大跨度、给区间），第 2 张 = 精测（按区间装夹、给最终值）。两遍输出都固定画在曲线图底部的红字横幅上。

## 1. 脚本流程（七步）

把 USAF 1951 黑白标靶装入 135 片夹（即「135 调焦卡」），片夹两端不对称垫高（按推荐流程即 B组 高于 A组），扫描得到长条图。沿长轴各段处于不同焦平面，必有一段恰好落在扫描仪最佳焦点。

`tilt_focus_sweep.py` 的七步如下：

1. 传入长条扫描单图 + 垫高量 `--lift-mm`
2. `crop_center_strip` 裁中央 80% 宽竖条（比例可用 `--strip` 调；只锁标靶主体，排除画幅差异）
3. 沿竖条高度均分 **n 份（默认 40，`--n` 可调）**
4. 逐份 `calculate_sharpness` 算 sharp（块内细密黑白精度锐度）
5. 逐份把彩色 strip 拆成 R/G/B 三通道，各跑一遍相同锐度算法；各通道按"归一化平顶容差 + 中位索引"选峰值份 `Y_c`，按 `Z_c = X × Y_c / n` 换算出各通道焦平面高度，高度差即**纵向色差 LoCA**（R−G / G−B / R−B，单位 µm）
6. 综合分 = **灰度锐度 sharp 本身**（`--w-sharp`，默认 1.0），按得分排名。
   - 色差（LoCA）是"焦平面位置差"而非逐份质量分，只画在下方面板作诊断，**不参与评分**。
7. **回截窗口（全宽）+ 物理换算**：取 `comp` 最高的那一份，连同前 5 份 + 后 5 份（边缘不足时自动收窄），从**原图全宽**截取该高度区间并 100% 画质保存，红框横贯全宽标出最高份；同时按公式算最佳锐度应垫高高度：**四个支脚统一垫起 = X × Y / n**（X = 当前高低差 mm，Y = 最佳份序号 1..n）。

**输出**：脚本只落盘两张图，所有逐份 sharp / 三通道峰值 / LoCA 与物理换算量**打印在控制台**（不再写 JSON）：

| 文件                       | 内容                                                                                                                   |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------- |
| `tilt_sweep_profile.png` | 双面板：上=灰度锐度得分曲线（绿影=窗口份数，红点=最高份）；下=R/G/B 三通道锐度曲线 + 各自峰值点（只诊断不计分，不标 LoCA）；**底部红字横幅 = 本遍固定结果**（第1遍=区间建议，第2遍=最终 0.1mm 推荐） |
| `tilt_best_window.jpg`   | 原图**全宽**回截窗口高度区间，**100% 画质**，红框横贯全宽标最高份                                                                              |

**核心结论**：四个支脚统一垫起高度 = **X × Y / n**（n = 均分数，默认 40；X = 当前高低差 mm，Y = 最佳份序号 1..n）。

## 2. 两遍精测法（推荐，定位精度提升约 3×）

单次 40 份在 4mm 跨度下分辨率约 `4/40 = 0.100mm/份`，对亚毫米级片夹垫高（0.1/0.2mm 垫片）仍偏粗。采用「粗测定位 + 精测细化」两遍法，把**覆盖宽度**与**定位分辨率**解耦（与上方「推荐流程」第 4–6 步一一对应）。

### 2.1 第 1 遍（粗）

大跨度保证峰值一定被覆盖、离焦对比强。高低差 X = 4mm（按推荐流程即 B组 垫高 4mm、A组 = 0）。

```bash
python tilt_focus_sweep.py <长条图> --lift-mm 4 --n 40
```

→ 脚本除给出 `Zf1`（如 `3.9mm`）外，会**直接打印第二遍精测建议**（跨度 1mm，分两种情形）：

- **常规（峰值未贴最后一份）**：区间 = **以 Zf1 居中** `Zf1−0.5 – Zf1+0.5` mm（低端若 <0 则钳到 0、跨度仍 1mm）。例：Zf1=3.9（第39份）→ **3.4 – 4.4 mm**；Zf1=3.4 → 2.9 – 3.9 mm。峰值落在第二遍正中，前后各覆盖 0.5mm。
- **唯一特例（峰值恰贴第一遍最后一份，第40份）**：区间 = **从 Zf1 起向上外探** `Zf1 – Zf1+1` mm。例：Zf1=4.0 → **4.0 – 5.0 mm**。原因：Zf1 已是第一遍实测最大值，真实最佳可能落在实测范围之外（更高处），若仍居中（3.5–4.5）会漏掉上方；故整段向上外推。**只此一种贴边情形外推，其余一律居中。**
- 装夹：低端(A组)垫区间下限 mm、高端(B组)垫上限 mm（例：Zf1=4.0 → A组 4.0mm、B组 5.0mm；Zf1=3.9 → A组 3.4mm、B组 4.4mm）；
- 并给出可直接照抄的第二遍命令（见 2.2）。分辨率 ≈ 4/40 = 0.100 mm/份。

### 2.2 第 2 遍（精）

**直接用第一遍脚本打印的区间**（跨度 1mm：常规低端 = Zf1−0.5、高端 = Zf1+0.5，Zf1 居中；峰值贴第40份时低端 = Zf1、高端 = Zf1+1 向上外探），n=10 提升分辨率。第一遍只需把区间缩进 1mm 内即可，不必精确估计 d。

- 物理垫高：**常规 = 低端(A组) Zf1−0.5 mm / 高端(B组) Zf1+0.5 mm**（低端<0 钳到 0）；**贴第40份特例 = 低端 Zf1 / 高端 Zf1+1**。例：Zf1=3.9（第39份）→ A组垫 3.4mm、B组垫 4.4mm；Zf1=4.0（第40份）→ A组垫 4.0mm、B组垫 5.0mm。
- 扫描后运行（**必须带 `--low-lift-mm`**，即低端绝对垫高 X；脚本靠"是否传了这个参数"判定第 2 遍，即使 X=0 也要写 `--low-lift-mm 0`）：

```bash
python tilt_focus_sweep.py <第二遍长条图> --lift-mm 1.0 --n 10 --low-lift-mm <区间下限>
```

→ 脚本在**图上底部红字 + 控制台**固定输出 **最终推荐垫高 = X.X – X.X+0.1 mm**（按 0.1mm 网格取整，绝对最佳 = 区间下限 + Zf2 落在区间内；分辨率 = 1.0/10 = 0.100 mm/份）。**四个支脚统一垫到这个区间即可，无需心算。**

### 2.3 校验与注意

- **遍次判定靠参数**：不带 `--low-lift-mm` = 第 1 遍（出区间建议）；带 `--low-lift-mm` = 第 2 遍（出最终推荐）。若第 1 遍建议低端 = 0mm，第 2 遍务必写 `--low-lift-mm 0`，否则会被当成第 1 遍。
- 第 2 遍峰值应落中间段（第 3–8/10 份）；若贴边（第 1 或 10 份）说明第 1 遍估计偏了，用新 Zf 重算 A/B组垫高再跑。特别地，若第 1 遍贴了最高份（第40份）已按 4–5mm 外探，第 2 遍仍贴最高份则说明真实值比 5mm 还高，需继续加大跨度重扫。
- 两遍必须**同张 135 调焦卡、同格、同方向**（顶部 = 低端 = 示意图 A组支脚，垫付高端 = 序号小端 = B组支脚），否则绝对基准漂移。
- 第二遍跨度 1mm，所有份都接近正焦、sharp 绝对差异小，但峰值附近对高度最敏感且 n=10 每份 5746px 统计稳，可定位；若想更细用 n=20（每份 0.05mm），短长条慎用避免块过薄。

## 3. 限制与建议

- 该度量对**标靶内容**敏感：真实 USAF 1951 各组线密度不同，若长条内某段正好全是极细线组，即使略离焦也可能给出较高 sharp。建议第一遍垫高量足够大（如 4mm），使离焦带来的锐度下降**明显超过**内容差异；或在目标区域使用内容均匀的细光栅条。
- 默认 40 份每份高度较小（约 75–110px），`calculate_sharpness` 的 `GaussianBlur(σ=18)` 仍能工作，但真实标靶在该尺度下必须仍有细密线组覆盖，否则指标会失效。短长条（如 4700px）第二遍用 n=10 单块更厚、统计更稳。

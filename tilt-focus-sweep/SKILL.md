# 倾斜标靶长条焦平面扫描 · 片夹垫高计算

## Overview

把 135 调焦卡（USAF 1951 黑白标靶）一端垫高、一端不垫，扫描出一张**长条图像**，
用本 skill 把长条沿斜面方向均分成 N 份，逐份测"细密黑白精度锐度"，找到综合锐度最高的
那一段，反推出**片夹应垫高的高度**。

核心公式（用户实测指定）：

```
设片夹高的一端相对低的一端垫高 X(mm)，长条均分 n 份，
扫描得到综合锐度最高的份序号 Y(1..n)，则
    焦平面高度 Zf = X × Y / n
```

- 四个支脚**统一垫起** `Zf` → 片夹整体平行于玻璃，整片落入焦平面。
- 或保持倾斜、把最清晰段移到长条正中 → 低端再调整 `X × (Y/n − 0.5)` mm。

为兼顾速度与精度，推荐**两遍精测法**：
1. 第一遍：大跨度（如 X=4mm）+ n=45，粗定位最佳高度 d。
2. 第二遍：以 d 为中心、±e（e=0.2mm）构造对称倾斜（跨度 2e），n=15，精定位。

## When to use

- 用户要校准胶片扫描仪片夹垫高、找最佳焦平面。
- 用户提供了一张"一端垫高的调焦卡长条扫描图"并要求算出垫高量。
- 用户的扫描图像出现离焦模糊，怀疑片夹与玻璃不平行。
- 需要把多次扫描配置按锐度做横向对比排名。

## 依赖安装

```bash
pip install -r requirements.txt
```

需要 `opencv-python-headless`（或 `opencv-python`）、`numpy`、`Pillow`。
所有脚本使用 `np.fromfile` + `cv2.imdecode` 读取图像，可正确处理含中文/Unicode 的文件路径。

## 快速开始

```bash
# 第一遍（粗）：高低差 4mm，均分 45 份
python tilt_focus_sweep.py <长条扫描图.jpg> --lift-mm 4 --n 45

# 第二遍（精）：中心 d，跨度 2e=0.4mm，低端垫高 = d-0.2，均分 15 份
python tilt_focus_sweep.py <新长条扫描图.jpg> --lift-mm 0.4 --n 15 --low-lift-mm <d-0.2>
```

输出（默认写在脚本同目录，可用 `--out <目录>` 指定）：
- `tilt_sweep_profile.png`：沿长条的 sharp / 反相CA / 综合 曲线 + 窗口标记。
- `tilt_best_window.jpg`：原图全宽回截最佳高度区间，红框圈出最高份。

全部数值（最佳份 Y、Zf、统一垫高、绝对最佳高度）打印在控制台。

## 参数说明

| 参数 | 含义 | 默认 |
|---|---|---|
| `--lift-mm` | 高低端垫高差 X(mm) | 0 |
| `--strip-mm` | 长条物理长度(mm)，用于把位置换算成 mm | 0 |
| `--low-lift-mm` | 第二遍低端绝对垫高(mm)，填后直接输出绝对最佳高度 | 0 |
| `--n` | 长条均分份数 | 45 |
| `--w-sharp` / `--w-ca` | 综合锐度中 锐度:色差 权重 | 0.7 / 0.3 |
| `--strip` | 中心竖条裁剪宽度(px)，用于锁定标靶主体 | 3500 |
| `--out` | 输出目录（默认脚本同目录） | 脚本同目录 |

## 注意事项

- **装载约定（固定）**：标靶菲林垫付高的一端 = 菲林序号小的一端 = 高端；扫描图像**顶部 = 低端**。
  因此份 #1 恒为图像顶部、即低端，Y 直接从图像顶部数起，无需方向开关。
- **同张卡一致性**：两遍必须用同一张调焦卡、同一格、同一方向，否则绝对基准漂移。
- **边缘截断**：综合最高份靠近两端时，回截窗口自动收窄、绝不越界（n≤11 时取整条）。
- **锐度度量对标靶内容敏感**：块越小越易被内容波动掩盖离焦信号；第二遍 n=15 比 n=45 更稳。
- `gen_rank_md.py` 为可选工具：从 `focus_history.json` 生成排名总榜（缺 `color_history.json` 时仅出 a/ 榜，不报错）。

# scans/ —— 你的扫描数据目录（私有，不入库）

本目录放置实际的底片扫描文件。**请勿把真实扫描图提交到 GitHub**（已被 `.gitignore` 排除）。

## 目录约定

每个「扫描配置」一个文件夹，放在本目录（或由 `FILM_SCAN_ROOT` 环境变量指定的根目录）下。
文件夹名需与 `scripts/rank_tiff.py` 中 `DEFAULT_GROUPS` 的「值」对应。

```
scans/
├── M_AR玻璃改_超薄片夹_1.5/      # 组 M 的 6+ 张扫描
│   ├── img001.tif
│   ├── img002.tif
│   └── ...
├── O_AR玻璃改_超薄片夹_2.0/      # 组 O
│   └── ...
└── X_AR玻璃改_超薄片夹_5mm_M10/  # 组 X
    └── ...
```

## 文件要求

- 文件名以 `img` 开头（如 `img001.tif`、`img300.tif`）。
- 每个文件夹 ≥ 6 张；同组自动取**最新 6 张**（按文件名倒序），重扫后新图会自动顶替旧图。
- 推荐 16bit TIFF（保留高光余量）；也支持 8bit JPEG/PNG。
- 同一次扫描的 6 张应是**同一底片、同一格位**的不同配置版本，才满足「同帧配对」前提。

# 扫描 gamma 标定方法（为什么是 1.8，怎么重测）

## 结论先行

被测机器（Epson V700 + 该版本驱动）在「无色彩校正 / 正片模式」下，
48bit TIFF 的 gamma 编码指数 **γ ≈ 1.8**，不是常见的 2.2。
逆线性化应为 `T = (V / 65535)^1.8`。换机器、换驱动版本、换扫描模式都必须重测。

## 证据链（同帧 Epson TIFF vs VueScan Raw）

用同一格底片分别以两种软件扫描，严格流程：

1. **几何配准**：SIFT + RANSAC 求两图单应矩阵（被测图需旋转 90° 对齐）。
2. **零插值取像素**：把一张图的网格采样点投回另一张原图，两边都从**原图直接取
   局部均值**，绝不对 warp 后的图算指标（插值会系统性污染拟合）。
3. **逐通道 log-log 拟合**：对有效亮度区（避开暗部噪声与高光饱和）做
   `log(线性值) ~ log(VueScan Raw 值)` 斜率扫描。

实测结果（约 34.7 万有效点，相关系数 0.996–0.998）：

| 线性化 gamma | 1.75 | **1.80** | 1.85 | 2.2 |
|---|---|---|---|---|
| log-log 斜率均值 | 0.965 | **0.992** | 1.020 | 1.213 |

斜率 = 1 意味着两图编码域一致 ⇒ γ = 1.8。用 2.2 线性化斜率 1.21，
说明 gamma 给高了，线性值被压得过低。

⚠️ 次要差异：G 通道斜率始终偏低约 0.03、R 通道比值离散偏大，说明除 gamma 外
还有轻微的通道处理（色罩 / 白平衡），做不到逐像素完全吻合。这不影响 gamma 判定。

## 复标定方法 A：同帧 VueScan Raw 对照（推荐）

1. 同一格底片：Epson Scan 用「无色彩校正 / 正片 / 48bit / 无压缩」扫一张；
   VueScan 用 `Raw file` 输出线性 TIFF 或 DNG（`dcraw -T -4 -D` 转线性）。
2. 按上面 1–3 步做配准 + 零插值采样 + log-log 斜率扫描，找斜率 = 1 的 gamma。
3. 注意两图曝光差（增益不同）只影响比例系数、不影响斜率，无需刻意统一曝光。

## 复标定方法 B：阶梯楔（独立基准）

扫一张 21 级灰阶（Stouffer 等），已知每级透射率 `T = 10^(-D)`，
每级取像素均值 V，拟合 `log(V) ~ log(T)` 斜率：

| 斜率 | 含义 |
|---|---|
| ≈ 1.0 | 线性（无 gamma 编码） |
| ≈ 0.56 | gamma 1.8（斜率 = 1/γ） |
| ≈ 0.45 | gamma 2.2 |

这是不依赖 VueScan 的独立基准，适合在怀疑软件对照有系统误差时交叉验证。

## 为什么这件事重要

gamma 猜错是**系统性错误**，比量化误差严重：按 2.2 逆 gamma 而实际是 1.8，
暗部密度会被系统性算错，负片色罩减不干净、残留偏色。
所以「先定标 gamma → 再浮点线性化 → 再进密度域」的顺序不能省。

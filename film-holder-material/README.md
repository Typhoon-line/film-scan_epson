# 片夹相关资料（film-holder-material）

本目录收录超薄片夹的设计稿、扫描成片预览和片夹图文详情，适用于已改装面板、校准过焦平面的扫描仪。需配合防牛顿玻璃搭配使用。另外可调高度片夹也在开发中。

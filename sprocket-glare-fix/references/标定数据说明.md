# 标定数据说明（异常备用，供 `deglare_learn.py seed` 用）

**定位：常规建档一律用 `deglare_learn.py add --with 新原图 --without 新对照`**——
它自己跑 SIFT + 差分 + 带内 lift 并写档案，不依赖本目录。
本目录的三个 JSON 是**异常备用**：仅当新原图有问题（边界探测失败 / SIFT 内点不足 /
对照扫坏）导致 `add` 走不通时，才用 `seed` 从这些历史采集结果一次性重建档案。

`seed` 命令读 `calibration/` 下三个 JSON：

## 1. `heal_log.json`

逐图的原始光晕强度 delta 与换算 amp：

```json
{
  "001": {"delta": 0.00087, "amp": 0.00165},
  "002": {"delta": 0.00021, "amp": 0.0004}
}
```

- key = 带孔图序号（`img001.tif` → `"001"`）
- `delta` = `L(无孔对照) − L(带孔图)` 在孔下的额外抬升（归一化 0–1）
- `amp` = `delta / SHAPE_MEAN`，`SHAPE_MEAN≈0.5294`（见 `deglare_core.SHAPE_MEAN`）

## 2. `halo_control_diff2.json`

SIFT 对齐与差分统计，结构：

```json
{
  "stats": {
    "001_007": {"dx": -12, "dy": 986, "inliers": 281, "...": "..."}
  }
}
```

- key = `带孔序号_无孔序号`（如 `1,7` → `"001_007"`）
- `dx/dy` = 对照图投到带孔图的纯平移（整数像素）
- `inliers` = SIFT/RANSAC 内点数，>30 才可信

## 3. `per_hole_band_probe.json`

逐孔屏幕区 delta 与带内 lift，用于估计 SNR 与逐孔系数：

```json
[
  {"n": 1, "screen": [0.0009, 0.0011, "..."], "lifts": [1.2, 1.1, "..."]}
]
```

- `n` = 带孔图序号
- `screen` = 逐孔屏幕区 delta 数组
- `lifts` = 逐孔带内抬升数组（孔下基带 − 邻孔间隙基带）

## 如何自己生成这些数据

如果只是**新增样本**，不需要 seed，直接用：

```bash
python deglare_learn.py add --name PROFILE --with A.tif --without B.tif
```

它会自动跑 SIFT + 差分 + 带内 lift 并写入档案。seed 只用于「从零批量重建档案」
且已有上述采集结果时。三个 JSON 的字段由 `deglare_learn.add_control()` 的
返回值与 `deglare_core.pair_delta()` / `band_lifts()` 给出，照格式组织即可。

## 注意

- 本目录的 JSON 是**一次性标定样本**，不是通用数据；换扫描流程要重新采集。
- 采集必须用「同流程、仅无齿孔」的对照扫描，否则差分无意义。

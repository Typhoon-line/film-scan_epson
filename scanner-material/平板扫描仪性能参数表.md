## 附录：技术术语解释

### 一、Dmax（最大光学密度）代表什么

**一句话**：Dmax 是扫描仪在**透射（扫底片）模式**下，能分辨出的"最黑程度"。数值越大，暗部细节保留越好。

**物理定义**  
光学密度（Optical Density, D）描述胶片"挡住多少光"：

```
D = -log10(透射率 T) = log10(入射光 / 透射光)
```

- **D = 0**：胶片全透明，光全通过（画面最亮 / 白）
- **D = 1**：只透过 10% 的光
- **D = 4**：只透过 0.01% 的光（极黑，几乎不透光）

密度轴是对数刻度——D 每加 1，透光量缩小 10 倍。

**标称 Dmax ≠ 真实可用 Dmax（重点）**  
平板胶片扫描仪标称的 Dmax（爱普生高端 4.0、佳能旗舰 3.8）是**实验室极限曝光条件下**测得的营销值。同一批机器在**正常扫描 / 观看条件**下实测只有 **≈ 2.2–2.5**，几乎所有消费级平板都落在此区间；真正的专用底扫 / 鼓扫才到 3.9–4.0。

| 概念        | 典型数值      | 说明              |
| --------- | --------- | --------------- |
| 标称 Dmax   | 3.4–4.0   | 厂商宣传，实验室极限曝光    |
| 真实可用 Dmax | ≈ 2.2–2.5 | 正常扫描 / 观看条件实测   |
| 底片暗部密度    | 3–4+      | 黑白 / 彩色负片暗部常见密度 |

### 二、灯管技术区别（CCFL vs LED）

平板胶片扫描仪照明光源主要分两代，区别不只是"亮不亮"，而是直接影响**预热等待、密度一致性、寿命、以及对老胶片的友好度**。

**对比**

| 维度      | CCFL（冷阴极荧光灯管）                                  | LED（ReadyScan LED / White LED）                       |
| ------- | ---------------------------------------------- | ---------------------------------------------------- |
| 代表机型    | X700 / X750 / X800 / X900 / X970；9950F / 9900F | X770 / X820 / X830 / X980；8800F / 9000F / 9000F MkII |
| 预热      | 需预热，数秒~数十秒才达稳定亮度与密度                            | 零预热，开机即扫，密度瞬时稳定                                      |
| 光谱      | 连续白光谱，色彩风格经典、过渡平滑                              | 白光 LED 阵列（部分机型 RGB 顺序曝光）                             |
| 寿命      | 有限（数千小时），老化后密度与色温漂移                            | 极长（数万小时），几乎不衰减                                       |
| 能耗 / 发热 | 相对较高，工作时发热明显                                   | 低，冷光源基本不发热                                           |
| 对胶片影响   | 需预热稳定；灯管衰减需定期校色；热辐射易致老片翘曲                      | 密度一致、免预热；无热辐射，对老胶片更友好                                |

**一句话区分**

- **CCFL** = 「经典色彩 + 需养护」：色彩风格讨喜，但灯管会老化、要预热、要定期校色。
- **LED** = 「即时 + 稳定 + 护片」：即开即扫、密度长期一致、不烤片。

**高端特例**

- **GT-X970 / V750 Pro**：在 CCFL 基础上叠加 **High Pass Optics（高通过光学组件）**——在 CCD 玻璃上镀抗反射膜、配高反射镜，减少光损与鬼影，是其区别于 V700 的独有升级。
- **GT-X980 / V800·V850**：唯一同时具备「双镜头系统 + LED 零预热」的旗舰，兼顾速度与画质。

**对 GT-X800 项目的意义**


GT-X800（= 4990）用的是 **CCFL**，所以：

1. 每次扫描前**务必预热**到灯管稳定，否则密度 / 色彩会漂移（换玻璃、调片夹后要重新跑分）。
2. 灯管老化是真实风险——若发现密度下滑、偏色，先怀疑灯管而非镜头。

### 三、光电元件（CCD 类型）解释

平板胶片扫描仪的感光元件普遍是 **CCD（电荷耦合器件）**，而非 CMOS。关键参数在**线数（line）**&#x4E0E;**微透镜（Microlens）**：

- **线数（N-line CCD）**：描述 CCD 上并排的感光线数量。6 线 = 每色 2 线（R/G/B × 2 交错）一次采集；12 线 = 翻倍，单次扫描能覆盖更多像素行，**直接决定扫描速度**。
- **On-Chip Microlens（片上微透镜）**：在每个 CCD 像素上覆盖微型聚光透镜，把更多光线汇聚到感光区，**提升感光度与信噪比**——在暗部（高 Dmax 区域）尤其重要。
- **MatrixCCD / 交替彩色 CCD（alternated colour CCD）**：通过相邻像素分别接收 R/G/B 实现彩色，配合微步进驱动（Micro Step Drive）在副扫描方向插值提升有效分辨率。

**线数不是越多越好，要看整机架构**：

- **单镜头机**（4870/4490/4990/V500/V550/V600）：靠 CCD 线数 + 微步进提升采样率。V500 一代把 6 线升到 **12 线 MatrixCCD**，是相对前代的主要提速手段。
- **双镜头机**（V700/V750/V800/V850）：胶片端与反射端用**不同焦距**的两组镜头切换，各自优化；CCD 本身维持 **6 线**，分辨率由镜头切换 + 微步进达成，不需要靠堆线数提速。

### 四、胶片扫描中的关键技术解释

**光路全链路（从光到数字）**  
胶片扫描本质是把"光穿过胶片后的强弱分布"转换成数字。整条链：

```
光源 (CCFL/LED)
   ↓
透射单元 TPU（光从胶片背面打透）
   ↓
胶片 + 片夹（平整定位、防牛顿环）
   ↓
镜头系统（单镜头 MatrixCCD / 双镜头双焦距）
   ↓
感光元件（6 线 / 12 线 CCD + 微透镜）
   ↓
ADC → 数字图像（位深 8 / 16 bit）
```

逐环节说明：

1. **光源**：提供稳定均匀的照明。CCFL 需预热稳定；LED 瞬时稳定。光源亮度与稳定性直接决定能压到多暗（Dmax 上限）。
2. **透射单元 TPU（Transparency Unit）**：把光从胶片**背面**打透，而非像反射稿那样从上方照。TPU 光路均匀性决定有无亮暗不均。
3. **胶片 + 片夹**：把胶片压平、定位。片夹不平整 → 胶片微翘 → 焦平面漂移 → 局部虚；胶片与玻璃间有空气隙 → **牛顿环**（薄膜干涉产生的同心环纹）。这正是自制片夹、用防牛顿环玻璃要解决的问题。
4. **镜头系统**：决定分辨率和像差。
   - **单镜头 MatrixCCD**（X700/X750/X770/X820/X830）：一个镜头兼顾反射与透射。
   - **双镜头系统**（X800/X900/X970/X980）：透射与反射模式用**不同焦距**的两组镜头，各自优化成像——透射模式走高分辨率镜头，这也是为什么 4990 及以上能标到 4800 / 6400 dpi 并支持 4×5。
5. **感光元件**：CCD 侧重动态范围与色彩层次。线数决定速度、微透镜决定感光度与信噪比（见第三节）。
6. **ADC（模数转换）**：把模拟光信号转成数字。位深（8 bit / 16 bit）决定暗部能分多少级——**位深比"标称 Dmax"更实在地影响暗部层次**。
